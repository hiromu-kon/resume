## 2. 略歴

2021年7月からエンジニアとしてキャリアをスタートし、フルスタックエンジニアとして開発業務に加え、プロジェクトマネジメント、技術基盤構築、教育、採用など幅広い業務に従事してきました。

1社目では未経験からエンジニアとしての基礎を築き、200店舗規模のドラッグストア向け業務システム開発に従事。業務影響の大きいシステムにおいて、バグの未然防止やSQLパフォーマンス改善に注力し、品質向上に貢献しました。

2社目では1人目のエンジニアとして入社し、メディアアプリ、ECサイト、ポイントアプリなど多様なプロジェクトをリード。技術選定や開発に加え、非エンジニアのクライアントにも伝わる平易な言葉での説明を心がけ、認識齟齬の少ない進行を実現しました。実装時はこまめな共有と確認を徹底し、信頼関係構築と品質担保を両立。経験の浅いメンバーが多いチームに対しても、相談しやすい環境づくりとフォローアップで生産性向上を支援しました。

これらの経験を経て、2025年9月より株式会社WorldHacksの執行役員に就任。現在は開発業務に加え、組織づくり、採用、開発体制整備にも関わり、開発組織の成長と事業推進に取り組んでいます。

## 4. この先やりたいこと

少人数チームでの開発を通じ、フロントエンド/バックエンド実装だけでなく、PM業務やメンバー育成にも関わりながら、プロダクトを一気通貫で推進してきました。これらの経験から、価値提供に必要な領域を越境していく働き方に強い魅力を感じています。

今後は一気通貫でプロダクトに向き合いつつ、特に強みとなる技術領域を深め、より高い専門性を発揮できるエンジニアを目指しています。具体的には、大規模サービスにおけるスケーラビリティ、パフォーマンス最適化、技術的負債の解消、継続改善可能なアーキテクチャ設計に強い関心があります。

また、技術実装にとどまらず、ビジネスサイドと密に連携しながら、ユーザー価値・事業価値へのインパクトを意識した提案と意思決定にも関わっていきたいと考えています。技術とビジネス双方を理解し、プロダクトを前進させる役割を担えるエンジニアを目指します。
